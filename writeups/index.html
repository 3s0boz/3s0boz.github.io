Selected machines

  • Support (HackTheBox, Windows AD)
    SMB share leaking a .NET tool, hidden LDAP attribute, Resource-Based Constrained Delegation with Impacket to SYSTEM on the domain controller.
  • Orion (HackTheBox, Linux)
    Craft CMS deserialization to PHP session injection and RCE, cracked database hash, argument injection in a loopback telnet daemon.
  • TwoMillion (HackTheBox, Linux)
    JavaScript deobfuscation, broken access control to admin, command injection in the VPN generator, kernel OverlayFS exploit.
  • Cap (HackTheBox, Linux)
    IDOR exposing a packet capture with cleartext FTP credentials, password reuse, Python with cap_setuid.
  • Bookstore (TryHackMe, Linux)
    LFI in a deprecated API version, Werkzeug debugger PIN from shell history, SUID binary gated by a reversible XOR check.
  • Tomghost (TryHackMe, Linux)
    Ghostcat (CVE-2020-1938) file read, PGP key cracking, sudo zip escalation.
  • UltraTech (TryHackMe, Linux)
    Command injection in a Node.js API, SQLite dump and cracked credentials, root through docker group membership.
  • Team (TryHackMe, Linux)
    Two virtual host discoveries and an LFI to an SSH key, sudo command injection, writable root cronjob.
  • Jump (TryHackMe, Linux)
    Five-level privilege escalation chain: cron-executed FTP upload, systemd PATH hijacking, writable helper script, less escape.
  • Blog (TryHackMe, Linux)
    WordPress user enumeration, XML-RPC credential attack, plugin RCE, custom SUID binary with a logic flaw.
  • Lookup (TryHackMe, Linux)
    Username enumeration on a login form, vulnerable elFinder to RCE, PATH hijacking and sudo look.
  • Fools Mate (TryHackMe, web)
    Business logic flaw: a chess API that never validates moves.
  • W1seGuy (TryHackMe, crypto)
    Known-plaintext attack against a repeating-key XOR service.

Nmap tooling

Two Python scripts written to speed up the first recon step in labs.

  • nmap_scan.py runs nmap -sV -sC against a target, saves the normal output to a file, and stops with a clear message when nmap is missing, the target does not resolve or the host does not answer ping probes.
  • nmap_parser.py reads -oN output and prints a table of open ports with service versions, followed by NSE script output per port and per host.
